Sub Manager (shared)

Portable version · Supabase history + live when configured, in-memory only otherwise · fictional sample roster

Portable source — no tracking. Game and history data are never stored in this browser; they live in Supabase (sign-in required) or in memory only. The one exception is the sign-in session itself, saved by Supabase Auth in this browser until you sign out. With Supabase configured (see README), finished games are saved to history and the live game syncs between the driver and a view-only phone. Without it, nothing is saved between reloads, including your preferred starting lineup. Share a setup or game with the texted-link tools on the Setup screen.
